# Product Overview

## Project Purpose
Turtle is a comprehensive NFT ecosystem built on blockchain technology, combining ERC-721 NFT minting, ERC-20 token economics, and DeFi staking mechanisms. The platform enables users to mint, trade, stake NFTs for token rewards, and interact with a redemption vault system.

## Value Proposition
- **NFT Collection**: Limited edition collection of 10,625 unique Turtle NFTs with reveal mechanics
- **Token Economics**: Native TURTLE ERC-20 token integrated across all platform features
- **Passive Income**: Stake NFTs to earn 10 TURTLE tokens per day per NFT
- **Liquidity Options**: Redemption vault for converting NFTs to tokens or swapping with vault NFTs
- **Community Engagement**: Faucet system for token distribution and user onboarding

## Key Features

### NFT Minting & Management
- Public batch minting (up to 20 NFTs per transaction)
- Dual payment options: native token (CRO) or TURTLE tokens
- Admin minting capabilities for airdrops and partnerships
- Pausable minting with burn functionality
- Base URI management for reveal events

### Earning/Staking System
- Stake NFTs to earn TURTLE tokens (10 tokens/day per NFT)
- Requires 35,000 TURTLE tokens as collateral per NFT
- Flexible claiming without unstaking
- Time-based withdrawal fees (10 CRO < 24h, 5 CRO < 72h, free after 72h)
- Daily reward calculation system

### Turtle Redemption Vault
- Deposit NFTs to receive TURTLE tokens based on pool ratio
- 1:1 NFT swap system (user NFTs ↔ vault NFTs) with TURTLE fee
- Direct CRO purchase of specific vault NFTs
- Swap fees remain locked in vault, increasing future deposit rewards
- Maximum 20 NFTs per transaction

### Faucet System
- 35,000 TURTLE tokens per claim (configurable)
- 5-minute cooldown between claims
- Owner-managed token distribution
- New user onboarding tool

### Web Application
- Nuxt 3-based progressive web app
- Vuetify UI components for modern interface
- Web3 wallet integration via Reown AppKit
- Real-time contract interactions with ethers.js
- Responsive design for mobile and desktop

## Target Users

### NFT Collectors
- Users seeking unique digital collectibles
- Community members interested in limited edition artwork
- Traders looking for NFT liquidity options

### DeFi Participants
- Stakers seeking passive income from NFT holdings
- Token holders utilizing the TURTLE ecosystem
- Users interested in NFT-backed yield generation

### Developers & Partners
- Projects integrating with Turtle contracts
- Developers building on the platform
- Partners receiving admin-minted NFTs

## Use Cases

1. **Collect & Hold**: Mint and hold Turtle NFTs as digital collectibles
2. **Stake for Yield**: Lock NFTs with TURTLE collateral to earn daily rewards
3. **Trade & Swap**: Use redemption vault for NFT-to-token conversion or 1:1 swaps
4. **Acquire Tokens**: Claim TURTLE tokens via faucet for ecosystem participation
5. **Community Building**: Participate in reveals, partnerships, and platform governance
